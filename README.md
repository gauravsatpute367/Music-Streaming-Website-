# Svara — Find your frequency

A responsive, no-build music discovery website with an original Hindi, Marathi, and English demo catalog.

## Run it

Open `index.html` in a modern browser. No install or build step is needed. To preview it on a phone on the same Wi-Fi network, serve this folder from your computer and open that local address on the phone.

## What works

- Search songs, artists, languages, and moods.
- Filter by Hindi, Marathi, or English; browse moods, trending, and favorites.
- Play, pause, skip, shuffle, repeat, seek, adjust volume, and create a local playlist.
- Favorites are saved in the current browser.
- The greeting, date, and update time follow your local clock.
- Audio previews are original instrumental sketches synthesized in real time by the browser's Web Audio API.

## About the audio

This is a front-end demo, not a catalog connected to a commercial music service. The included track names and artists are fictional, and the playable previews are generated locally; they are not full vocal recordings. Real songs, user accounts, synchronized playlists, and a globally shared live catalog require licensed audio, a streaming backend, and hosting.
